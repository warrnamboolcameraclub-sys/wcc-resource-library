# Permanent Website Pages

Place metadata-enabled permanent Warrnambool Camera Club website pages here when they are added to the Resource Library.

The automation should eventually index both:

- `content/newsletters/*.html`
- `content/pages/*.html`

Do not add routine navigation, contact or gallery pages just because they exist. Add substantive reference material members may reasonably search for again, such as current competition rules, workshops, VAPS information, educational resources and downloadable guides.
