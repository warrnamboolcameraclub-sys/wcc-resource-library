## Important historical/indexing notes

1. **Tip codes B007, I007 and A007** were not printed in the Issue 011 HTML. They have been added from the project's established tip-number tracking so the historical tip library remains continuous.
2. **Competition Judging with Johanna Botman** is listed only as “September” in this issue. The metadata deliberately does not insert the later-known 3 September date.
3. **Warrnambool Marathon** is listed only as “Late September”. No later event date has been back-filled.
4. **Warrnambool Show Photography Competition** is listed only as “October”. No exact date has been invented.
5. **Werribee Open Range Zoo** is marked `confirmed` because Issue 011 itself says the outing was “now looking locked in”. This preserves the state of knowledge in that historical edition even though later planning changed.
6. The generic `.footer` class has been renamed to `.wcc-newsletter-footer` to avoid Zenfolio footer-style collisions. Visible footer wording is unchanged.
7. Existing short anchor IDs such as `#bird` and `#editing` were replaced with globally unique permanent IDs, and the “In this issue” links were updated accordingly.
8. The Lightroom PDF link is now indexed as a `resource` while retaining the same published URL.
