# Initial GitHub Upload

This package is designed to become the root contents of the `wcc-resource-library` repository.

Do **not** upload the ZIP file itself as a repository file.

1. Extract the ZIP locally.
2. Open the extracted `wcc-resource-library` folder.
3. Upload/commit the **contents of that folder** so that `README.md`, `content/`, `config/`, `.github/` and the other top-level entries sit directly at the repository root.
4. Do not enable GitHub Pages yet.
5. After the first commit, confirm that the GitHub Actions workflow `WCC Resource Library - Source Validation` completes successfully.

The first workflow is validation-only and does not publish a website.
