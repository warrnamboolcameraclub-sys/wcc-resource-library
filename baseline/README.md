# Baseline and Migration Reference

Files in this directory are reference material for the initial GitHub migration.

- `current-resource-library-index.html` is the current hand-built Resource Library used to reconcile generated records and preserve front-end behaviour.
- `public-url-map.json` records the known public URLs for Issues 001–012 and is retained as migration/audit evidence.

Neither file is part of the future weekly editorial workflow.

In particular, `public-url-map.json` is **not authoritative**. Each canonical newsletter's embedded `data-url` is the production source for its public URL.
